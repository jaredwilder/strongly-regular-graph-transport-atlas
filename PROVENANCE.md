# Provenance

## Buried source

The focused repository was created after the September 2026 archive-mining pass found a mathematical program inside an archive named:

```text
graph-bridge-real-delivery.zip
```

The archive did not advertise mathematics in its filename and therefore belonged to the class of material missed by an earlier filename-filtered sweep.

## Public recovery surface before this repo

The program was summarized publicly in:

`jaredwilder/mathematics-under-the-wrong-filename`

That public recovery records:

- 119 strongly-regular-graph parameter tuples from Brouwer;
- 91 existing / 28 nonexisting;
- 141 verified composable transport edges;
- eight transports;
- 211 endpoints;
- zero disagreements;
- an explicit refusal to identify `Matrix.IsHadamard` with an order-level Hadamard existence proposition.

## Why this focused home exists

A buried-program paragraph is not an adequate canonical home for a 119-row parameter atlas plus a 141-edge transport system. This repository exists so that the exact source tables, proof dependencies, rejected bridges and verifier receipts can be recovered without mixing them with unrelated archive-mining findings.

## Priority / novelty boundary

The first-public timestamp for the buried recovery predates this focused repository. This repository is therefore a **promotion and consolidation**, not an attempt to reset priority.

The source audit does not by itself establish historical novelty of the parameter entries or transports. Literature/catalogue provenance must remain attached row-by-row when the exact atlas is reconstructed.
